# SHTns 3.7 reference fixtures

These fixtures are generated by the public C API of the exact upstream SHTns
`v3.7` release (`4e04fba84ea156974df5edaf4ee856c0f4f86e77`, interface
`0x307A0`, archive SHA-256
`5c6a2d585211232a030c6fbbb08f6a794dd1aab987d31511ef53deea12138d97`).
They are independent oracles for SHTnsKit.jl; the generator uses only the
documented public declarations and fields in `shtns.h` and never calls Julia
or SHTnsKit code.

Build and regenerate from the repository root with:

```sh
make -C reference/shtns37 \
  SHTNS_PREFIX=/path/to/shtns-3.7 \
  FFTW_PREFIX=/path/to/fftw
reference/shtns37/generate test/fixtures/shtns37
```

The generator uses `SHT_PHI_CONTIGUOUS`, converts every number explicitly to
little-endian byte order, and writes SHA-256 checksums to `manifest.toml`.
SHTns 3.7 CPU transforms are FP64-only. Any Float32 fixtures are produced by
an explicitly recorded downcast of an independently computed FP64 SHTns
oracle, never by SHTnsKit.jl.

The payload convention is SHTnsKit's public convention. The generator records
physical `mmax` (while SHTns receives its stored-order count), converts the
documented negative-order complex phase and toroidal sign once, scales fixed-m
outputs by their recorded `fixed_mode_scale`, serializes phi-contiguous SHTns
spatial arrays in Julia column-major order, converts `st_dt_matrix` to the
source-indexed public representation, and records the public positive Z angle.
