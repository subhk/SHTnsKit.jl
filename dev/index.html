SHTnsKit.jl

SHTnsKit.jl is a pure-Julia spherical harmonic transform library for scalar, vector, and QST fields. The same mathematical conventions are available across serial CPU, CUDA, AMDGPU, and MPI/PencilArrays backends.

Highlights

  • Scalar, complex, spheroidal/toroidal, and QST transforms.
  • Gauss–Legendre, regular Fejér, pole-inclusive regular, and Driscoll–Healy grids.
  • Orthonormal, four-pi, and Schmidt normalization; configurable Condon–Shortley phase, real-field normalization, and Robert form.
  • Reusable serial and distributed plans, packed layouts, batch transforms, rotations, differential operators, and diagnostics.
  • Vendor-native CUDA and AMDGPU array dispatch, plus MPI-distributed CPU/GPU paths with explicitly tracked parity status.
  • ForwardDiff, Zygote, ChainRulesCore, and LoopVectorization extensions.

See the SHTns 3.7 parity matrix for the executable capability inventory and backend certification status.

Install

using Pkg
Pkg.add("SHTnsKit")

Optional functionality is activated by loading its dependencies:

Pkg.add(["CUDA", "GPUArrays", "KernelAbstractions"])       # NVIDIA
Pkg.add(["AMDGPU", "GPUArrays", "KernelAbstractions"])     # AMD
Pkg.add(["MPI", "PencilArrays", "PencilFFTs"])             # distributed

First transform

using SHTnsKit

cfg = create_gauss_config(16, 18)

# Start with band-limited coefficients so analysis/synthesis is an exact
# roundtrip at the configured resolution.
coefficients = zeros(ComplexF64, cfg.lmax + 1, cfg.mmax + 1)
coefficients[3, 1] = 1.0
field = synthesis(cfg, coefficients)
recovered = analysis(cfg, field)

@assert maximum(abs, recovered - coefficients) < 1e-12
nothing

For repeated transforms, preallocate outputs and reuse an SHTPlan:

using SHTnsKit

cfg = create_gauss_config(16, 18)
plan = SHTPlan(cfg; use_rfft=true)
field = rand(cfg.nlat, cfg.nlon)
coefficients = zeros(ComplexF64, cfg.lmax + 1, cfg.mmax + 1)
reconstructed = zeros(cfg.nlat, cfg.nlon)

analysis!(plan, coefficients, field)
synthesis!(plan, reconstructed, coefficients)
size(reconstructed)
(18, 34)
GPU dispatch

analysis(cfg, device_array) and synthesis(cfg, device_coefficients) keep data on the detected CUDA or AMDGPU device. Strict GPU() dispatch never silently falls back to the CPU. See GPU Acceleration for device transfer and fallback details.
