Installation

SHTnsKit 2.0 supports Julia 1.10, 1.11, and 1.12 on Linux, macOS, and Windows. The core package is pure Julia; FFTW.jl is installed automatically.

Core package

using Pkg
Pkg.add("SHTnsKit")

Verify the installation with a small band-limited roundtrip:

using SHTnsKit

cfg = create_gauss_config(8, 10)
coefficients = zeros(ComplexF64, cfg.lmax + 1, cfg.mmax + 1)
coefficients[3, 2] = 0.5 - 0.25im
field = synthesis(cfg, coefficients)
recovered = analysis(cfg, field)

@assert maximum(abs, recovered - coefficients) < 1e-12
(lmax=cfg.lmax, grid=size(field))
(lmax = 8, grid = (10, 18))

Configurations are managed by Julia's garbage collector; explicit teardown is not required.

Optional capabilities

Install only the row your application needs. Loading those packages activates the matching SHTnsKit extension automatically.

CapabilityPackages
NVIDIA GPUCUDA, GPUArrays, GPUArraysCore, KernelAbstractions
AMD GPUAMDGPU, GPUArrays, GPUArraysCore, KernelAbstractions
MPI distributedMPI, PencilArrays, PencilFFTs
SIMD helpersLoopVectorization
Forward-mode ADForwardDiff
Reverse-mode ADZygote

For example:

using Pkg
Pkg.add(["MPI", "PencilArrays", "PencilFFTs"])

Continue with GPU Acceleration or Distributed Computing for a minimal working program.

Common setup problems

A grid constructor rejects the size. Gauss grids require nlat >= lmax + 1 and nlon >= 2*mmax + 1. See Grid Types for the equiangular-grid constraints.

An optional method is missing. Load every package in its extension row in the same Julia session. For MPI, use:

using MPI, PencilArrays, PencilFFTs, SHTnsKit

Older code no longer runs. Version 2 removed ambiguous flags, device symbols, and compatibility plan signatures. See Migrating to SHTnsKit v2.0.
